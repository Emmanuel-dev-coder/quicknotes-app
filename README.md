# QuickNotes

QuickNotes is a simple note-taking web app that lets users create, categorize, search, delete, and save notes in their browser.

## Features

- Add notes
- Personal, Work, and Study categories
- Note validation with a 200-character limit
- Delete notes
- Search notes
- Save notes using localStorage
- Responsive layout for smaller screens

## How to Run Locally

1. Clone or download this repository.
2. Open the `quicknotes-app` folder in VS Code.
3. Open `index.html` with Live Server or open it directly in a web browser.
